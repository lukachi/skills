# Judge panel

**Use when the solution space is wide and one attempt, iterated, will converge
on whatever the first attempt happened to be.**

An agent that produces one design and then improves it is improving that design.
The alternatives it did not write are not competing.

## The shape

1. **Generate N independent attempts from different angles** — cheapest-first,
   risk-first, user-first, whatever the axes of this problem are. Independent
   means each is written without the others in context.
2. **Score them with judges that did not write them**, on stated criteria.
3. **Synthesise from the winner**, grafting what the runners-up did better.

The runners-up are the point. A panel that only picks a winner has run an
expensive tournament to get one attempt.

## When not to

- The answer is already settled and this is delivery.
- The criteria are not written down. Judges then score on taste, and taste is
  what the panel was supposed to replace.
