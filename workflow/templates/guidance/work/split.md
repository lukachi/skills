# The units

Break the work into vertical slices, each one a thin path through the whole
system rather than a layer of it.

**Size by scope and coherence.** Not by what fits in one agent session — that
framing taught agents to stop halfway through a context that was still wide
open, and they did.

Declare which acceptance criteria each unit serves. Nothing else is required:
there are no blocking edges to compute and no frontier to respect. A map that
came out of grilling can be worked efficiently in an order no dependency graph
would predict, and enforcing one restrains you for nothing.

Write your own notes on a unit as you learn things about it. That field is what
replaces the scheduler.
