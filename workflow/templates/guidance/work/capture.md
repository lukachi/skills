# Captures

Something worth keeping that this flow does not own goes here — a bug noticed in
passing, a gotcha, an idea for later.

It does not become a bundle. Opening a workload because you noticed something is
how a repository ends up with eleven active records nobody agreed to, and the
command that would do it refuses while a flow is open.

A capture the maintainer alone can settle is marked as awaiting them and put to
them as one decision, when there is a reason to. It is not a backlog to read
out.
