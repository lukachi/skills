# Research Report Contract

Every investigation produces a Markdown report containing:

## Objective
The research question, scope, and relevant constraints.

## Findings
Key discoveries and conclusions, with traceable evidence for significant claims.

## Evidence
Primary sources, URLs, code references, and verification dates.
External code references include the upstream revision and location where possible. Reports never cite our own repositories.

## Unknowns
Unresolved questions, conflicting evidence, and investigation limitations.

## Recommendations
Evidence-based suggestions, explicitly distinguished from established facts.
