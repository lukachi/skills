# Staged for phase two

state key, and the states it belongs to do not exist yet.

- `reconstruct-project-knowledge`, `process-raw-intake`, `assemble-trajectories`
  — the reconstruction case, deliberately sequenced after the changes flow.
  Intake is absorbed into reconstruction and raw material moves under it, so
  these three are re-cut together rather than one at a time.
- `setup-workflow-environment` — installation, which changes shape once the leaf
  profile is removed.
- `operate-project-knowledge`, `curate-project-knowledge` — knowledge-repository
  routing. Most of it dies with the router; what survives is the four promotion
  routes, already carried into `guidance/curate/routing.md`.

Nothing here is installed or loaded. It is source material for the next pass, and
this directory is empty when that pass is done.
