# The probe round

Ask whether the written pages can answer without reopening the source.

This is the check that survives. Line-range reading receipts were the agent
grading itself — it asserted that a file was inspected and nothing observed it,
so coverage, completion, and the weight behind every claim inherited the
overstatement. A probe tests the output instead, which is the only thing that
catches material that was fetched and never read.

**A different agent asks the questions.** Asking yourself what you might have
missed returns what you already know — the same failure as an agent reviewing
its own code, reached from the other side.

Every subject that reached a page is covered by at least one question. A probe
that cannot be answered from the pages is repair work, not a waiver.
