## Project workflow

This block is managed by `wfctl`. Read `.workflow/config.json` and all files under `.workflow/rules/` before project work.

- Invoke the installed `analyze-with-graphify` skill before code navigation, search, debugging, or architectural analysis.
- Treat Graphify as the primary navigation tool; text search is supplementary.
- Classify work with the installed `manage-project-work` skill before changing project state.
- Do not claim completion without the installed `verify-project-work` skill.
- Preserve uncertainty and report missing evidence instead of guessing.
